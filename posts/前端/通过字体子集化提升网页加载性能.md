## 前言

中文字体文件通常有 5-10 MB，包含上万个字形。但一个普通页面可能只用到几百个字。完整字体会拖慢首屏加载，影响 LCP 指标。

**字体子集化**：从原字体中只提取会用到的字符，生成精简版字体文件。

实际效果：

- 字体文件从 5 MB 降到 200 KB
- 首屏字体加载时间从 2s 降到 0.3s
- LCP 改善 40-60%

---

## 使用 font-slice 生成子集

**安装**

```bash
npm install --save-dev font-slice
```

**编写脚本** `slice-font.js`

```js
const createFontSlice = require('font-slice')
const path = require('path')

createFontSlice({
  fontPath: path.resolve(__dirname, 'YourFont.ttf'),
  outputDir: path.resolve(__dirname, './font-output'),
})
```

**执行**

```bash
node slice-font.js
```

生成内容：

- `font.css` - 字体声明文件
- 多个切分后的字体文件（通常 50-100 个）

---

## 项目中使用

1. 复制生成的 `font.css` 和字体文件到 `public/fonts`

2. 引入字体样式

```css
@import './fonts/font.css';
```

3. 应用字体

```css
body {
  font-family: 'YourFont', sans-serif;
}
```

## 优化建议

- 定期扫描项目文字内容，更新字体子集
- 使用 `font-display: swap` 避免字体阻塞渲染
- 结合 CDN 和长缓存策略进一步提升性能
- 监控字体加载时间，确保优化效果

实测数据：

- 优化前：字体 5.2 MB，加载 2.1s
- 优化后：字体 50 KB，加载 0.4~0.7s
