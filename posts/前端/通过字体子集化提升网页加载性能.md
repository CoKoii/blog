## 前言

中文字体文件通常有 5-10 MB，包含上万个字形。但一个普通页面可能只用到几百个字。完整字体会拖慢首屏加载，影响 LCP 指标。

**字体子集化**：将一个完整字体按字符切分成多个小字体文件，页面上只加载需要的子集字体。

## 使用 font-slice 生成子集

**安装**

```bash
npm install --save-dev font-slice
```

**编写脚本** `slice-font.js`

```js
const createFontSlice = require('font-slice')
const path = require('path')

createFontSlice({
  fontPath: path.resolve(__dirname, 'YourFont.ttf'),
  outputDir: path.resolve(__dirname, './font-output'),
})
```

**执行**

```bash
node slice-font.js
```

生成内容：

- `font.css` - 字体声明文件
- 多个切分后的字体文件（通常 100 个）

## 项目中使用

1. 复制生成的 `font.css` 和字体文件到 `public/fonts`

2. 引入字体样式

```css
@import './fonts/font.css';
```

3. 应用字体

```css
body {
  font-family: 'YourFont';
}
```

## 实战应用

以开源字体 [LXGW WenKai](https://github.com/lxgw/LxgwWenKai) 为例：

1. 下载字体文件 `LXGWWenKai-Light.ttf` (26.9 MB)

2. 使用 `font-slice` 切分

```js
const createFontSlice = require('font-slice')
const path = require('path')

createFontSlice({
  fontPath: path.resolve(__dirname, 'LXGWWenKai-Light.ttf'),
  outputDir: path.resolve(__dirname, './dist'),
})
```

3. 生成产物:

- font.css
- index.html (预览页)
- LXGWWenKai-Light.1.woff2
- LXGWWenKai-Light.2.woff2
- LXGWWenKai-Light.3.woff2
- ... (平均每个文件 ~30 KB)

4. 引入并使用

```html
<link rel="stylesheet" href="./font.css" />
<style>
  body {
    font-family: 'LXGWWenKai-Light';
  }
</style>
```
